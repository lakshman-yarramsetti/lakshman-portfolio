## Run Locally

This is a static HTML/CSS/JavaScript portfolio and does not require a backend server or environment variables.

Clone the repository:

```bash
git clone https://github.com/lakshman-yarramsetti/lakshman-portfolio.git
```

Navigate into the project:

```bash
cd lakshman-portfolio
```

Open `index.html` directly in a browser.

Alternatively, serve the project folder using any static web server if you prefer to access it through a local URL.
