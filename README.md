# Lakshman Yarramsetti Portfolio

Personal portfolio website for Lakshman Yarramsetti, a Full Stack Developer focused on Node.js, NestJS, React, React Native, PostgreSQL, and backend-driven full stack development.

This portfolio presents production experience, technical skills, company project responsibilities, and selected GitHub projects built around REST APIs, role-based access control, dashboards, AWS S3 file workflows, and responsive frontend implementation.

## Live Website

This project is designed to be deployed using GitHub Pages.

Expected live URL format:

```text
https://lakshman-yarramsetti.github.io/lakshman-portfolio/
```
