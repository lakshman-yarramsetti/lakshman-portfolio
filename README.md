## Run Locally

This is a static HTML, CSS, and JavaScript portfolio. It does not require a backend server or environment variables.

Clone the repository:

```bash
git clone https://github.com/lakshman-yarramsetti/lakshman-portfolio.git
```

Navigate into the project:

```bash
cd lakshman-portfolio
```

Open `index.html` directly in a browser, or serve the project folder using a static web server.

## Deployment

The website is designed to be deployed using GitHub Pages.
