# Lakshman Yarramsetti Portfolio

Personal portfolio website for Lakshman Yarramsetti, a Full Stack Developer with 3.5 years of experience focused on Node.js, NestJS, Express.js, React.js, TypeScript, PostgreSQL, MySQL, REST API development, and backend-driven full-stack applications.

This portfolio presents professional experience, technical skills, production responsibilities, and selected GitHub projects covering RESTful API development, authentication and authorization, role-based access control, database design and optimization, AWS S3 file workflows, dashboards, reporting, and responsive frontend development.
